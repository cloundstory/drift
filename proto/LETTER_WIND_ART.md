## 0. หลักรวม (Global)

- **เทคนิค:** Canvas 2D, procedural line-art ล้วน. ไม่มี raster, ไม่มี WebGL, ไม่มี particle simulation, ไม่มีหน้าตา/ตัวละคร
- **พื้นหลัง:** linear gradient 165° จาก `#dfe2e6` (บน) → `#eee9de` (ล่าง) — warm-cool
- **เส้นหลัก:** `rgba(84,90,104,a)` (เทาอมน้ำเงิน) — ปรับ alpha ตามความเข้ม
- **accent ทอง:** `#c69a54` (จดหมาย/แสงแจ่มใส) — เชื่อม Between Stars
- **ตัวอักษร UI:** Georgia/serif, letter-spacing กว้าง, opacity ต่ำ (0.3–0.5)
- **ปรัชญา:** คมชัดจากความเนี้ยบของเส้น ไม่ใช่จำนวนเส้น · สบายตา · contemplative · ให้รู้สึกเองมากกว่าบอกตรง ๆ
- **DPR cap = 2** เสมอ (มือถือ)

## 1. จดหมาย = กระดาษคลี่ (unfolded sheet)
`ref: letter-flutter.html`

- **โครง:** mesh ~14 cols × 18 rows (portrait), warp ด้วยคลื่นที่วิ่งผ่านแผ่น
- **การไหว:** travelling wave — `phase = u*freq*2π + v*1.5 - t*speed`
  - `sway = 8 + wind*46` (px), `freq = 1.2 + wind*3.2`, `speed = 0.6 + wind*2.6`
  - ขอบท้าย (right edge, u→1) สะบัดมากกว่า: `edge = pow(u,1.6)`, `cornerBoost`
  - เอียงต้านลม: `tilt = (wind-0.35)*0.5`
- **แสง/เงา:** shade จาก z ของ ripple → quad สว่าง/มืดตามคลื่น (fake depth)
- **โปร่งแสง:** alpha `0.9 - max(0,shade)*0.18`
- **สี aging:** สด `[236,234,225]` → เก่า `[206,190,150]` ตาม `age`
- **เส้นหมึก (แทนตัวอักษร):** เส้น warp ตาม mesh, `rgba(43,43,47, 0.32 - age*0.12)`, เว้นบรรทัดเป็นย่อหน้า, ragged right
- **ทำไมกระดาษคลี่:** บางพอให้ลมเล่น + เปิดหน้าให้ร่องรอยลงเต็ม (ซอง=หนัก/ปิด, นกพับ=ตรรกะถึงยาก)

### ร่องรอยบนจดหมาย (traces) — วาดจากพารามิเตอร์ ไม่เก็บรูป
- **ฝน (คราบ):** radial gradient bloom สีน้ำตาลจาง `rgba(90,84,70,a)` ที่ขอบ/มุม **ห้ามทับตัวอักษร**
- **พายุ (ยับ):** เพิ่มความยับ/ขอบช้ำ (degree ตามความรุนแรง)
- **อายุ:** สีเข้มขึ้นเหมือนกระดาษเก่า
- เก็บเป็น params เช่น `{rain:3, storm:1, days:2}` → render Canvas ตอนเปิด
- **เพดานสูงสุด:** ต้องยังดู "ผ่านการเดินทางมา" ไม่ใช่ "เสียหาย/ถูกขยำ" (จูนด้วยตา)

## 2. GLOBE = ลูกโลกเส้น 2.5D
`ref: globe-study.html`

- **วาดเอง ไม่ใช้ Three.js** — projection: lat/lng → sphere xyz → rotate (yaw+pitch) → project `(CX+x*R, CY-y*R)`, z ใช้เช็ก occlusion
- **เส้นโครง:** lat ทุก 30° (−60..60), lng ทุก 30°. บาง จาง `rgba(90,96,105,0.28)`, rim เข้มกว่าเล็กน้อย
- **filled disc จาง ๆ:** radial gradient ให้รู้ว่าเป็นทรงตัน
- **นิ่ง:** ไม่หมุนเอง. ปัดเพื่อหมุน + inertia (decay ×0.94) แล้วหยุด
- **ปัดตามมือ:** `rotY -= dx; rotX += dy` (drag ขวา→หน้าโลกไปขวา). pitch clamp ±1.3 — **สำคัญกับ first impression**
- **occlusion:** ~~วาดเฉพาะช่วง z≥0~~ → **แก้รอบ 22 ส.ค. 69:** เส้นโลก (กริด+ชายฝั่ง) ซีกหลัง **เห็นจาง ๆ ทะลุ** (×0.13) วาดก่อนเนื้อทรงกลมให้ถูกกลบตามจริง — เพื่อให้อ่านออกว่าเป็นทรงกลมโปร่ง ไม่ใช่วงกลมแบนที่มีเส้นโค้ง
  **เส้นทางจดหมายยังตัดสนิทที่ z<0 เหมือนเดิม** เพราะตำแหน่งจดหมายต้องไม่กำกวมว่าอยู่ซีกไหน
- **ทำไมไม่ใช่ 2D map:** เส้นข้ามแปซิฟิกขาดขอบ เสีย "โลกทั้งใบ"
- **ทำไมไม่ใช่ Three.js:** หนักเกินจำเป็นสำหรับ เส้น+จุด+พายุ = over-engineer

### เส้นชายฝั่ง (เพิ่ม 22 ส.ค. 69)
- **ที่มา:** Natural Earth 110m ผ่าน world-atlas (public domain) → Douglas-Peucker 0.35° → **101 เส้น / 2,105 จุด / 8.5KB**
- **encode:** 1 จุด = 4 ตัวอักษร base64 (lng,lat ละเอียด 0.25° ≈ 0.5px ที่ R=120) คั่นเส้นด้วย `|` — แปลงเป็นเวกเตอร์ครั้งเดียวตอนโหลด
- **ข้อควรรู้ตอน simplify:** Douglas-Peucker ใช้กับ ring ปิดตรง ๆ ไม่ได้ (จุดแรก=จุดสุดท้าย → ระยะตั้งฉากเป็น 0 หมด ทวีปยุบเหลือ 2 จุด) ต้องหั่น ring ที่จุดไกลสุดจากจุดเริ่มก่อน
- **น้ำหนัก:** ชายฝั่ง `.46` > กริด `.26` — ชายฝั่งคือเนื้อหา กริดเป็นแค่โครง
- **เหตุผล:** ก่อนหน้านี้จดหมายบินบนความว่างเปล่า ดูไม่ออกว่าอยู่เหนือทะเลจีนใต้หรือกลางแปซิฟิก โลกเลยเป็นของประดับ ไม่ใช่สนามที่เรื่องเกิดขึ้น

### กลางวัน-กลางคืน (เพิ่ม 22 ส.ค. 69 · ทำเป็น "มีแสง/ไม่มีแสง" จริงในรอบเดียวกัน)

**บทเรียน:** รอบแรกทำด้วยการลด opacity ของเส้นฝั่งมืด — ไม่ได้ผล เพราะพื้นหลังยังสว่างเท่าเดิม
สมองอ่านว่า "ไกลออกไป/หมอกบัง" ไม่ใช่ "มืด" **กลางคืนต้องมีพื้นมืดให้แสงตัด**

- **ดวงอาทิตย์:** subsolar point จริงจากเวลา UTC + วันในปี (declination = −23.44°·cos(360/365.24·(doy+10)))
- **รูปทรงของซีกมืด:** เส้นแบ่ง = วงกลมใหญ่ที่ตั้งฉากกับทิศดวงอาทิตย์ → project → เอาส่วนที่ z≥0
  แล้วปิดรูปด้วยส่วนโค้งของขอบโลกฝั่งกลางคืน (เลือกฝั่งด้วยการ unrotate จุดกลางส่วนโค้งกลับไปทดสอบกับทิศดวงอาทิตย์)
- **พื้นมืด:** radial gradient ลึกสุด `rgba(34,40,60,.50)` ที่จุดตรงข้ามดวงอาทิตย์ → จางเป็น `.10` ตรงสนธยา (clip ด้วยรูปทรงข้างบน)
- **เส้นกลับขั้ว:** ฝั่งกลางวันเป็นหมึก `84,90,104` · ฝั่งกลางคืนเป็นสีอ่อน `214,226,244` — ทั้งสองไล่ข้ามกันตรงรอยต่อ = สนธยา
- **ไฟเมือง:** Natural Earth populated places (public domain) 202 เมือง ≥200,000 คน · 1 เมือง = 5 ตัวอักษร (~1KB)
  ติดเฉพาะจุดที่ `dot(v,sun) < −0.02` สว่างตาม log ประชากร · เมืองใหญ่ (m>0.6) มี glow จาง ๆ
  **แยกจากจุดจดหมายด้วย:** เล็กกว่า · ไม่มี halo ใหญ่ · ไม่ขยับ · โผล่เฉพาะฝั่งมืด
- **เส้นขอบแสง:** เส้นบาง `rgba(228,214,186,.45)` ตามแนวรอยต่อ ให้ขอบของแสงมีรูปทรง
- **ชั้นบรรยากาศ:** ขอบโลก 3 ชั้นซ้อน — ทอง `198,154,84` ด้านโดนแดด · น้ำเงิน `126,150,196` ด้านมืด
- **เส้นทางจดหมาย** ต้องมี casing สีอ่อนรองข้างใต้ ไม่งั้นหายไปกับพื้นมืด
- **วัดจริง:** กลางวัน 174–190 · กลางคืน 71–93 (พื้นกระดาษ 231) — ต่างกัน 3 เท่าของเวอร์ชันไล่ความจาง (220 vs 199)

### perf: โลกเป็น layer แยก
- โลกนิ่งเกือบตลอด → วาดลง canvas ซ่อนแล้ว blit ทุกเฟรม วาดใหม่เฉพาะตอนหมุน / เปลี่ยนขนาด / ดวงอาทิตย์ขยับ (ทุก 5 นาที)
- ตอนหมุนใช้โหมด fast (stride 2, ไม่วาดซีกหลัง) — วัดจริง **1.1ms** ตอนหมุน · **2.7ms** เต็มคุณภาพ
- เส้นถูกจัดกลุ่มตามระดับ alpha แล้ว stroke ทีเดียวต่อกลุ่ม → 3,100 จุดเหลือ stroke ไม่กี่ครั้ง
- ทั้งฉาก (โลก + 6 จดหมาย + พายุ) = **2.84ms/เฟรม** · ตอนหมุน **3.45ms** จากงบ 16ms

### บนโลก
- **เส้นทาง:** great circle ด้วย slerp(a,b,t) → project แต่ละจุด, occlude หลังโลก. สี `rgba(120,110,88,0.9)`
- **ต้นทาง:** จุดทึบ. **ปลายทาง:** วงกลมกลวง. จาง (alpha 0.25) เมื่ออยู่หลังโลก
- **ลำดับชั้น:** โลก(จาง) < เส้นทาง(กลาง) < จดหมาย+พายุ(เด่น)

### จดหมายบน globe (LOD ไกล = จุด ไม่ใช่ mesh)
- จุดทอง `rgba(210,168,96,a)` r≈2.8 + halo radial gradient r≈9
- ตำแหน่งจาก slerp(home,dest, prog) โดย prog มาจาก timestamp

## 3. ชุดสภาพอากาศ 5 ระดับ
`ref: weather-set.html` · เรียงความรุนแรง · ทุกตัวอ้าง "ลมก้อนเดียวกัน" (ทิศ+ความแรง)

### 3.1 แจ่มใส (clear) — เบาสุดโดยตั้งใจ
- แสงนวลทอง radial `rgba(198,154,84, 0.14→0)` + เส้นอากาศนิ่งหายใจ 2 เส้น (quadratic โค้งเบา)
- เป็นสถานะพื้นฐาน — ต้องไม่กลบพายุ

### 3.2 ลม (wind) = **ริ้วไล่จาง (แบบ 6 ที่เลือก)**
`ref: ribbon-wind.html → wind6`
- ริ้ว 4 เส้น น้อย โปร่ง
- วาดทีละ segment, alpha ไล่: **เข้มด้านต้นลม → จางด้านปลายลม** `a = (0.06+intensity*0.28) * pow(along, 0.7)`
- `along = flowDir>0 ? f : (1-f)` → กลับทิศตามลม
- drift ทั้งชุดตามทิศ: `t*(0.4+intensity*0.5)*flowDir`
- amp `4 + intensity*7`
- **ไล่จางบอกทิศลมในตัว ไม่ต้องมีลูกศร** — เข้ากับ contemplative

### 3.3 ฝนปรอย (drizzle)
`ref: weather-set.html → rainC`
- ขีดสั้นเฉียง `len = 2 + depth*4`, กระจายถี่ (n≈30+intensity*26) + หมอกจาง radial ข้างหลัง
- ตกลง + วนซ้ำ (wrap), depth → ใกล้เข้ม/ไกลจาง
- เฉียงตามลม: `lean = windDir * 0.55`

### 3.4 ฝนหนัก (rain)
`ref: weather-set.html → rainA`
- ม่านเส้นเฉียงยาว `len = 7 + rand*5`, n≈13+intensity*15
- ตกลง+วนซ้ำ, depth ชัด (near เข้มหนา / far จางบาง)
- เฉียงตามลม lean เดียวกับ drizzle

### 3.5 พายุ (storm) — จอด/หาย
`ref: globe-study.html / weather-set.html → drawStorm + spiralArm`
- **log-spiral 3 แขน** สวีปกว้าง: `r = size*breathe*pow(f, 0.62)`, `turns = 0.72 + intensity*0.28` (รอบน้อย = เปิดกว้าง)
- แต่ละแขนวาด 2 ชั้น: ghost หนา (`lw 5`, alpha ต่ำ = เมฆ) + core คม (`lw 1.4`)
- ปลายแขน **fade** `pow(1-f, 0.7)` → เมฆสลาย
- wisps สั้นระหว่างแขน (rich)
- **ตาพายุ:** เจาะรูโปร่ง (`destination-out`) + glow รอบ + rim เส้นบาง
- หมุนช้า `t*(0.35+intensity*0.6)` + หายใจ `1+sin(t*1.8)*0.06`
- ขนาด/ความเข้ม/ความเร็ว = ตามความรุนแรง
- **❌ ห้ามมีเส้นรัศมี / วงนอกทึบ** → กลายเป็นใยแมงมุม (บทเรียนจากรอบแก้)

## 4. กฎภาพรวมสภาพอากาศ

- ฝน/พายุ **เฉียงตามทิศลมจริง** — มีทั้งซ้าย/ขวา ไม่ fix ข้างเดียว (ฝนไม่เฉียงข้างเดียวตลอด)
- จุดหนึ่งบนเส้นทาง = สภาพอากาศเดียว **ไม่ซ้อนกัน**
- render เฉพาะจุดหน้าโลก (z≥0)
- อธิบายลมเป็น **ภาษามนุษย์/บทกวี** ("วันนี้ลมดี") ไม่ใช่ตัวเลข/เวกเตอร์
- **ตัดทิ้ง** (ไม่กระทบกลไก): หิมะ, เมฆลอยเฉย ๆ, ฟ้าผ่า
- **หมอก:** เฟสหลัง (กระทบการเห็นตำแหน่ง ไม่ใช่ความเร็ว)

## 5. Mobile Performance (งานอาร์ตต้องเคารพ)

- **LOD:** globe = จดหมายเป็นจุด (ไม่ mesh) · เปิดอ่าน = mesh เต็ม ฉบับเดียว globe หยุด/เบลอ
- DPR cap 2, ลด mesh resolution บนจอเล็ก
- หยุด animation เมื่อ tab ซ่อน + เคารพ `prefers-reduced-motion`
- พายุรายละเอียดเต็ม เฉพาะตอนแตะดูใกล้ (ถ้าจำเป็น) ไม่ใช่ทุกจุดพร้อมกัน
- เพดานจำนวนจดหมาย animate พร้อมกัน; เกิน = เส้น static

- ความเข้มรวมของร่องรอยตอนเดินทาง ≥5 วัน (ต้องดูบนมือถือจริง)
- **ความเข้มของซีกกลางคืน** — ตอนนี้ลึกสุด alpha .50 ต้องดูด้วยตาว่า "มืดพอให้รู้สึก" หรือ "เข้มจนกลายเป็น dashboard"
- **ไฟเมืองแยกจากจุดจดหมายได้จริงไหม** — สีทองเหมือนกัน ต่างที่ขนาด/halo/การเคลื่อนไหว ถ้าสับสนต้องเปลี่ยนสีเมืองให้เย็นลง
