# drift

จดหมายที่ใช้เวลาเดินทางจริง เพราะลมจริงเป็นคนพาไป

เขียนจดหมาย เลือกปลายทาง แล้วปล่อยให้ลมพา — เส้นทางกับเวลาที่ใช้
คำนวณจากพยากรณ์ลมจริงของ [Open-Meteo](https://open-meteo.com/)
จดหมายอาจถูกลมพาอ้อม จอดรอพายุ หรือหลงทางไปเลยก็ได้

**หลักการกำกับ: ลมคือพระเอก** — ทุกอย่างในแอปมีอยู่เพื่อให้เห็นลม
ไม่ใช่ให้ลมเป็นฉากหลังของอย่างอื่น

## โครงสร้าง

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด — ไฟล์เดียว ไม่มี dependency ไม่มี build step |
| `sw.js` | service worker · ใช้งานออฟไลน์ได้ |
| `wind/` | แคชลมของภูมิภาค — สร้างอัตโนมัติ อย่าแก้มือ |
| `tools/fetch_wind.py` | ตัวดึงลมมาเก็บเป็นแคช |
| `.github/workflows/wind.yml` | รันตัวดึงทุก 6 ชั่วโมง |
| `drift-demo.html` · `drift-th.html` | หน้าโชว์ สร้างจากแกนเดียวกับแอป |
| `proto/` | ต้นแบบงานภาพ |

**เอกสารหลัก**

- `NEXT.md` — เหลืออะไรบ้าง **เปิด session ใหม่เริ่มที่นี่**
- `DRIFT_DECISIONS.md` — บันทึกการตัดสินใจทุกข้อพร้อมเหตุผลและตัวเลขที่วัดได้ **อ่านอันนี้ก่อน**
- `BUILD_NOTES.md` — วิธี build หน้าโชว์และแคชลม
- `LETTER_WIND_CONCEPT.md` — สเปกตั้งต้น (บางส่วนถูกแทนที่แล้ว อ่านคู่กับ DECISIONS เสมอ)
- `AUDIT_20260824.md` — ผลตรวจงานรอบล่าสุด

## รันในเครื่อง

```bash
python -m http.server 8777
```

แล้วเปิด <http://localhost:8777/>

เปิดจากไฟล์ตรง ๆ (`file://`) ก็ได้ แต่ลิงก์จดหมายจะใช้ได้เฉพาะเครื่องตัวเอง
และแคชลมจะโหลดไม่ได้ (แอปจะถอยไปยิง API เอง)

## แคชลม

```bash
python tools/fetch_wind.py
```

ดึงลม 1,480 จุดครอบไทยและทะเลรอบข้าง เขียน `wind/th.bin` (~55 KB)
ใช้ไลบรารีมาตรฐานล้วน ใช้เวลาราว 2 นาที

บนของจริงไม่ต้องรันมือ — workflow รันให้ทุก 6 ชั่วโมง
รายละเอียดและงบโควตาอยู่ใน `BUILD_NOTES.md` กับข้อ 58 ของ `DRIFT_DECISIONS.md`

## สถานะ

เฟส 1 — **ไม่มี backend** ทุกอย่างที่ผู้รับต้องใช้อยู่ในลิงก์
ผู้ส่งกับผู้รับต้องคำนวณเส้นทางออกมาตรงกันทุกหลัก

เฟส 2 (ยังไม่เริ่ม) — ล็อกอิน โควตา และของที่ระลึกระหว่างทาง
